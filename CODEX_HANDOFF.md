# 2. Product Vision

OFFICE is an **AI Corporate Office OS**.

The product should feel like:

> "A miniature autonomous AI company that I can enter, observe, control and manage."

It is NOT:

- a normal SaaS dashboard with a 3D background
- a fake animated office
- a hardcoded employee simulation

It IS:

- a real multi-agent operating system
- represented by a living interactive 3D corporate office
- with real backend state controlling visible employee behavior

Core invariant:

```
AI DECISION
    ↓
TASK / EVENT
    ↓
DATABASE / RUNTIME
    ↓
3D VISUALIZATION
```

Never invert this into fake 3D actions pretending that AI work occurred.

# 6. Employee Lifecycle

Canonical state:

```
SLEEPING
  ↓
QUEUED
  ↓
WORKING
  ↓
WALKING
  ↓
COLLABORATING
  ↓
WAITING
  ↓
COMPLETED
  ↓
SLEEPING
```

Failure path:

```
WORKING
  ↓
FAILED
  ↓
BLOCKED
  ↓
REPAIR
  ↓
WORKING
```

Rules:

- only employees with meaningful work wake
- sleeping employees should be visually quiet and computationally cheap
- walking must correspond to actual workflow reasons
- collaboration must correspond to real handoffs/dependencies
- completed agents return to sleep unless immediately reassigned

# 25. Performance Rules

Target smooth desktop rendering.

Avoid:

- React setState every frame
- one network request per employee
- duplicate heavy GLB loads
- expensive animation for sleeping workers
- uncontrolled texture sizes
- excessive shadows
- unnecessary postprocessing

Use:

- caching
- LOD
- instancing
- reused geometry
- reused materials
- selective animation
- capped pixel ratio where appropriate

Test eventually at:

- 10
- 25
- 50
- 100 agents
